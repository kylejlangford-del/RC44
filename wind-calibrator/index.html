Calibration

Wind calibrator

Load the CSV log exported from the boat's B&G H5000 system. Gives you suggested values for the same tables a professional speedo/upwash calibration covers — MHU/TWA offset, boat speed vs heel, upwash angle and upwash speed — computed from port/starboard tack comparisons during steady sailing. You review and type the numbers into the H5000 yourself.

1. Log file

Select the .zip or .gz export downloaded straight off your phone — the page unzips it and reads the CSVs inside, no need to unzip it yourself first. You can also select one or more already-unzipped CSV files directly (a session is often split into several numbered files — select them all at once).

2. Measured current (optional, recommended)

Enter current readings from the day (e.g. from a drift-measurement app) so the boat-speed table corrects for tide rather than assuming flat water. Nearest reading by time is used.
