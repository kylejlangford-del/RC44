Wind calibrator

Load the CSV log exported from the boat's B&G H5000 system. The analysis compares port vs starboard tack readings during steady sailing to suggest corrections for the H5000's editable wind-angle, wind-speed and boat-speed tables. You review and enter the numbers into the B&G system yourself — this tool never talks to the boat directly.

1. Log file

Select one or more CSV files from the log export (a session is often split into several numbered files — you can select them all at once).

2. Steady-state filter

Only samples matching these thresholds are used, so tacks, mark roundings and manoeuvres don't skew the averages.
